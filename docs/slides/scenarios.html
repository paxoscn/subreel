edge-tts 的 WordBoundary 事件直接给出每个词的真实起止时间，零 ASR 误差——最准的一条路。

输入
📄 script.txt
想看下现在AI对图片的理解能力
到什么程度了。
subreel tts voice.mp3 voice.words.json
subreel
v0.1.0
# 1. 配音 + 逐词时间轴 subreel tts --text script.txt \ --voice zh-CN-XiaoxiaoNeural \ --out voice.mp3 # 2. 渲染三种产物 subreel render voice.mp3 \ --timings voice.words.json \ --formats green,webm,mov

CJK 标点优先断行

场景 C 已有时间轴 → 直接渲染

时间轴在自己手里：任何工具都能驱动 subreel

只要你的对齐工具能输出 words.json（Audio2Subtitles、WhisperX、自研对齐都行），subreel 只负责画。

输入
🗂 my-alignment.json
{
  "words": [
    {"text": "那后面拜托它把清明上河图",
     "start": 12.34, "end": 15.12},
    {"text": "全图3D化也是美事一桩",
     "start": 15.12, "end": 17.60}
  ]
}
--timings voice.mp3
subreel
只负责渲染
subreel render voice.mp3 \ --timings my-alignment.json \ --formats green,webm,mov
格式、字体、字号、颜色、位置
全部可用命令行参数覆盖
成片
subs-green.mp4 · 1280×720
想要透明通道？换 --formats mov 即可 ProRes 4444 带真 alpha，达芬奇 / PR / FCP 通吃
subs-alpha.mov subs-alpha.webm subs-green.mp4
words.jsondocs: README › words.json timing format
适用：已有对齐数据、批量重渲染、UI 里可视化调样式
